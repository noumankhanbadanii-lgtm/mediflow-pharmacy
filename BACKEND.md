MediFlow data and operations

The private Site's dispatch access policy protects this shared store. Do not make the Site public without adding per-store authorization to all API endpoints.

Records persist in Cloudflare D1. Each action updates a versioned JSON snapshot in one atomic conditional statement. Concurrent sessions retry against current stock; financial, stock and audit changes commit together. Request IDs deduplicate the most recent 500 operations.

This initial small-store edition limits snapshots to 1.5 MB. It is not an unlimited archive or native offline desktop program. Export backups regularly; a normalized archival database migration is required as store history approaches capacity. The API returns a clear capacity error without saving partial changes.

All sale quantities use the medicine's labelled unit. Pack/strip conversion is not implied. Purchase and sale records are immutable. Returns link to original invoices, cap quantities, proportionally include invoice discount/tax and refund paid value after reducing remaining customer debt. Returned expired or damaged items go to quarantine and do not increase saleable stock. Return refunds record money paid out; customer payments record money received. Supplier payments reduce payable balances.

Demo records are loaded only by an explicit action into an empty store; initial database migrations contain schema only. Store backup import requires an explicit RESTORE confirmation and validates key fields and references before atomically replacing the snapshot. Imports remain bounded by the snapshot capacity.
